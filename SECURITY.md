# Security Policy

## Reporting
Please report suspected vulnerabilities privately through GitHub's security reporting features when available. Do not include real credentials, private extension packages, or personal browsing data in public issues.

## Scope and trust model
Browser Permission Audit is a static, offline manifest analyzer. It does not install extensions, execute extension code, contact browser stores, or inspect browsing history. Treat audit results as decision support rather than proof that an extension is safe or malicious.

## Supported version
Security fixes target the latest release on `main`.
